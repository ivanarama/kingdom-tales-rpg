# Сказки Королевства (Kingdom Tales RPG)

Ламповая пошаговая тактическая RPG, вдохновлённая лучшими элементами **King's Bounty («Легенда о рыцаре»)** и **Heroes of Might and Magic III**, но без замков и рутины строительства.

## Особенности проекта

- **Ламповый сказочный интерфейс:**
  - Окна и свитки из теплого пергамента с золочеными виньетками и уголками.
  - Деревянные резные кнопки с латунной окантовкой.
  - Атмосферный саундтрек (живая средневековая акустическая лютня и флейта) и приятные тактильные звуки (шелест страниц книги магии, звон золотых монет, звон клинков).
- **Карта приключений (World Map):**
  - Путешествие по сказочному королевству в роли благородного паладина — Рыцаря Аларика.
  - Посещение интерактивных сказочных объектов:
    - **Водяная мельница:** радушный мельник делится золотом из казны.
    - **Святилище Маны:** исцеляет магическую энергию героя и дарует постоянный бонус к Колдовству.
    - **Сундук с сокровищами:** классический выбор HoMM — забрать золото в казну или раздать крестьянам ради опыта.
    - **Роща Фей:** наём метких лесных лучниц.
    - **Засады разбойников:** бесшовный переход в тактический бой!
- **Тактический гексагональный бой (Battle Arena):**
  - Живописная поляна с мягкой гексагональной сеткой.
  - Шкала инициативы с круглыми золотыми медальонами существ вверху экрана.
  - Иллюстрированные существа со счетчиками численности в золотых плашках: Королевские Грифоны, Лучницы-Феи, Древние Древни, Лесные Волки, Гоблины-копейщики.
  - **Книга Заклинаний героя:** прямо во время боя герой может открыть книгу магии и сотворить Огненный Шар, Исцеление, Благословение или Ускорение!

## Быстрый запуск

Запустите файл [run_game.bat](file:///C:/Projects/mm_rpg_monolithic_gemini/run_game.bat) двойным кликом или выполните команду:

```bash
"C:\Projects\tools\godot-4.7.2\Godot_v4.7.2-stable_win64.exe" --path "C:\Projects\mm_rpg_monolithic_gemini"
```

## Тесты

Перед мержем обязательно гоняйте тестовый гейт ([run_tests.bat](file:///C:/Projects/mm_rpg_monolithic_gemini/run_tests.bat)):

```bash
run_tests.bat
```

Скрипт запускает набор сценой (`res://tests/test_runner.tscn`) headless и
проверяет вывод: «ALL 38 TEST SUITES PASSED» и отсутствие SCRIPT ERROR.
Запускать именно им — Godot возвращает код 0 даже при упавшем скрипте.
