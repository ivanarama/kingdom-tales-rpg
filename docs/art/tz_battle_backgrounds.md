# ТЗ на арт: фоны боя по главам и для боссов

Сейчас все бои идут на одном фоне — летний луг с замком (`assets/art/battle/meadow_bg.jpg`), включая Проклятые Топи и Пик Дракона. Механика своих фонов готова. Если положить файл по указанному пути, бой возьмёт его; пока файла нет, остаётся луг. Код менять не нужно.

## Как подключается

`BattleArena.background_path` ищет файлы по порядку:

1. `assets/art/battle/bg_<id боя>.jpg` — свой фон у конкретного боя (боссы);
2. `assets/art/battle/bg_chapter_<глава>.jpg` — фон главы;
3. иначе остаётся луг из сцены.

Демо-бои на Арене — всегда на лугу.

## Требования

| Параметр | Значение |
|---|---|
| Формат | JPG, качество ~90 |
| Размер | 1920 × 1080 (16 : 9). Нынешний луг — 1376 × 768; подойдёт любой 16 : 9 не меньше этого |
| Масштаб | фон растягивается с сохранением пропорций и обрезкой по краям (`KEEP_ASPECT_COVERED`). На телефонах 19,5 : 9 срезается верх и низ, поэтому важное не ближе 8 % к верхнему и нижнему краю |
| Стиль | как у луга: живописная сказочная иллюстрация, мягкий тёплый свет, насыщенные, но не кислотные цвета; светлая сказка даже для Топей и Лича |

### Композиция

Эталон — `meadow_bg.jpg`: деревья обрамляют края, ориентиры на горизонте, в центре ровный луг, цветы на переднем плане.

- **Поле боя** занимает середину кадра — примерно **x 15–93 %, y 14–78 %**. С прямоугольным полем из PR #29 это x 15–80 %. Поверх лежат полупрозрачные гексы и спрайты отрядов, поэтому здесь нужна **ровная, спокойно освещённая земля** с мягкой малоконтрастной фактурой: трава, мох, пепел, плиты. Без ярких пятен, глубоких теней, воды во весь участок и крупных предметов.
- **Горизонт** — на ~35–42 % высоты сверху. Ориентиры (замок, цитадель, вулкан, горы) — у горизонта, между рамками.
- **Рамки по бокам** (0–15 % и 88–100 % ширины): деревья, скалы, шатры — то, что задаёт место.
- **Нижние ~20 %** закрыты интерфейсом: слева панель героя, в центре лог, справа кнопка заклинаний. Здесь уместны детали переднего плана (цветы, камыши, камни), но ничего важного.
- **Без** текста, рамок, персонажей и существ: отряды на поле ставит игра.

## Как проверить

1. Положить файл, запустить бой в нужной главе (или с нужным боссом): фон сменился.
2. Гексы и отряды хорошо читаются на поле, ничего важного не спрятано под панелями.
3. **Если влит PR #11** (настроение боя для Топей и Пика): он подкрашивает фон шейдером. С настоящими фонами Топей и Пика подкраску стоит ослабить — `BattleMood.MOODS`, параметры `tint` / `saturation`.
4. **Тест 52** (`tests/test_runner.gd`) остаётся зелёным: он проверяет только запасной луг.
