# ТЗ на арт: иллюстрации к сказочным встречам

Окно встречи на карте (`data/map_events.json`) показывает картинку между заголовком и текстом, если она нарисована. Пока картинки нет, окно остаётся текстовым. Код менять не нужно: достаточно положить файл.

## Как подключается

- **Путь:** `assets/art/events/<имя>.png`. Имя по умолчанию равно id встречи; поле `image` в JSON позволяет нескольким встречам делить одну картинку. Так у трёх стадий пастушки одна картинка `ch1_shepherd.png`.
- **Отображение:** в окне картинка занимает ~340 × 170 px (формат 2 : 1) по центру, под ней текст и кнопки.

## Требования

| Параметр | Значение |
|---|---|
| Формат | PNG, 1024 × 512 px (2 : 1), sRGB |
| Края | мягкая виньетка, растворяющаяся в цвет пергамента (≈ `#E9DCC0`) или в прозрачность — без жёсткой рамки |
| Композиция | один главный сюжет по центру, крупно; читается в 340 × 170: без мелких деталей и толпы |
| Стиль | как весь арт игры: живописная иллюстрация сказки, мягкий тёплый свет, светлый добрый тон |
| Запрещено | текст, подписи, рамки, водяные знаки |

**Промпт-заготовка (EN), подставить сюжет:** *storybook illustration vignette, {SCENE}, painterly fairy-tale style, soft warm light, one clear subject in the center, wide 2:1 composition, soft vignette edges fading to parchment color, no text, no frame*

## Как проверить

1. Положить файл и открыть главу.
2. Подойти к встрече: картинка появится над текстом.
3. Закрыть окно: другие окна, например окно мельницы, открываются без картинки.
4. **Тест 53** (`tests/test_runner.gd`) остаётся зелёным.
