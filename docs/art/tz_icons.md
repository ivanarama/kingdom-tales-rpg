# ТЗ на арт: значки объектов карты и иконки заклинаний

Механика готова. Если положить файл по указанному пути, игра сама возьмёт его вместо общего значка; пока файла нет, остаётся прежний. Код менять не нужно.

## 1. Значки объектов карты

### Что сейчас

У всех объектов карты — один из семи общих значков 32×32 (`assets/art/world/icon_*.png`): книга, свиток, сундук, кристалл, костёр, врата, мечи. Мельница, склеп и кузница выглядят как костёр, все жилища — как книга. На карте они отличаются только подписью в окне.

### Как подключается

`WorldView` для каждого типа объекта ищет файлы по порядку:

1. `assets/art/world/objects/<тип>_ch<глава>.png` — вариант для главы (необязательный);
2. `assets/art/world/objects/<тип>.png` — общий для всех глав.

Если нет ни того ни другого, остаётся общий значок. Список типов — `WorldView.MAP_OBJECT_ICON_TYPES`. Тест 52 проверяет, что в нём есть все объекты всех трёх карт.

### Требования

| Параметр | Значение |
|---|---|
| Формат | PNG, RGBA (прозрачный фон), 128 × 128 px |
| Отображение | в игре 48 × 48 на клетке 64 × 64, чуть выше центра; мягкую круглую тень под объектом рисует движок — свою большую тень не нужно |
| Вид | миниатюра объекта карты приключений в духе HoMM III: сверху-спереди (≈ 3/4 с юга), объект целиком, по центру, низ основания на ~85 % высоты холста, объект занимает ~80 % холста |
| Стиль | живописный, как остальной арт игры: тёплый свет сверху слева, насыщенные неяркие цвета; светлая сказка, даже у склепа и костяных врат |
| Читаемость | узнаётся в 48 px: крупные формы, один главный цвет, без мелкой детализации по краям |
| Запрещено | текст, рамка, фон, клетка травы под объектом |

## 2. Иконки заклинаний

### Что сейчас

Файлы `assets/art/spells/spell_<id>.png`, 100 × 100. Это глянцевый круглый медальон с золотым ободком и белым символом. Рисованных символов только четыре: солнце, молния, пламя, крест. Остальные девять иконок — их перекраски, поэтому, например, «Молния» и «Замедление» различаются только цветом.

### Требования

| Параметр | Значение |
|---|---|
| Формат | PNG, RGBA, 100 × 100 px |
| Вид | как у существующих: глянцевый круглый медальон, тонкий золотой ободок, цветной фон, светлый символ по центру; за пределами круга прозрачно |
| Читаемость | различаются по **символу**, а не только по цвету; узнаются в 48 px (кнопки заклинаний в бою) |

## 3. Как проверить

1. **Значки карты.** Положить файлы, открыть главу — объекты на карте с новыми значками (см. таблицу типов выше).
2. **Иконки заклинаний.** Книга заклинаний и кнопки заклинаний в бою.
3. **Тест 52** (`tests/test_runner.gd`) остаётся зелёным: он проверяет только полноту списка типов и запасные значки.
