# Идеи фич и roadmap (анализ после ревью 0.1.1)

> **Статус 0.2.0:** реализованы пп. 1–10 и 13 (частично 12, 14);
> веб-сборка (п. 11) настроена и проверена. Ниже текст сохранён как
> исходный анализ; галочки отмечают выполненное.

> Предложения к CONCEPT.md. Ничего из этого нельзя делать без триажа против
> CONCEPT.md — сначала столпы, потом код. Порядок внутри групп — по
> соотношению «ценность игрока / трудозатраты».

## Быстрые победы (1–2 вечера каждая)

1. ✅ **Настройки звука в игре.** `SoundManager` уже хранит `master/music/sfx`
   громкости, но в UI их негде крутить. Окно «Настройки» (3 слайдера +
   сохранение в `user://`) — самый дешёвый UX-прирост.
2. ✅ **Слоты сохранений.** Сейчас один `savegame.json`. 3 слота + автосейв
   (со сводкой в меню «Продолжить») — классика жанра, инфраструктура
   сохранений уже есть.
3. ✅ **Скорость боя / кнопка «×2».** Анимации атак фиксированы (0.14–0.3 с +
   таймеры). Глобальный множитель `Engine.time_scale` на 1.5–2× для боя —
   бойцы с 30+ отрядами скажут спасибо.
4. ✅ **Ежедневный совет в подсказке.** При старте дня — плашка «Совет дня»
   (механики: сломанная стрела, мораль, отпор). Дёшево, а обучает.
5. ✅ **Итог боя.** Окно победы уже есть — добавить статистику: раунды,
   нанесённый урон, потери в разрезе отрядов (данные легко копить в бою).

## Средние фичи (по одному релизу MINOR на штуку)

6. ✅ **ИИ с магией героя.** У вражеского «лича-некроманта» просится свой
   набор: огненный шар по самой толстой пачке игрока раз в 2–3 раунда.
   Это поднимет сложность «Герой/Легенда» без новых юнитов. Реализация —
   в `_handle_ai_turn` по образцу `_execute_spell` (зеркальная структура
   «вражеской книги»).
7. ✅ **Новые существа по канону.** CONCEPT разрешает расширение ростера.
   Кандидаты в той же «светлой» стилистике: «Светлые пегасы» (летуны-
   перехватчики), «Каменные стражи обелиска» (танки с отражением),
   «Лисы-оборотни» (быстрые, ослабляют ответ врага). Каждому — токен,
   спрайт, запись в `unit_data.gd`, тест на пассивку.
   **Приоритет — дракон и лич**: сейчас они используют спрайты грифона и
   древня (плейсхолдеры бьют по канону сильнее всего).
8. ✅ **Новые заклинания светлой школы.** «Вдохновение» (снятие дебаффов с
   отряда + бонус морали), «Щит света» (поглощение урона N единиц),
   «Возмездие» (контратака при получении урона). Пассивки уже есть —
   щит ложится в `take_damage`.
9. ✅ **Артефакты с боевыми эффектами.** Артефакты сейчас дают только статы.
   «Рог доблести» (1 раз за бой: +инициатива всему войску), «Мантия
   странника» (шанс уклонения). Копится в `game_state`, применяется в
   `battle_arena` при старте боя.
10. ✅ **Вторая глава сюжета для гл. 2/3**: у глав 2–3 уже есть уникальные
    карты и стражи — добавить по босу-диалогу и эпилогу (как у гл.1 с
    рощей фей) — низкие трудозатраты, высокий «сюжетный» выигрыш.

## Крупные (по дорожной карте CONCEPT)

11. ✅ **Веб-сборка.** Уже в roadmap CONCEPT. После OGG-конверсии вес позволит
    WASM-сборку (~40–50 МБ; дальше можно резать качество музыки). Прогнать
    тесты на web-экспорте (аудио и тач-инпут — главные риски).
12. **Редактор «сказочных» встреч**: вынести 17+ конфигов встреч из
    `battle_arena.gd` в JSON/.tres (тоже в духе конвейера: контент правится
    без кода), затем — процедурные «дорожные засады» к недельным событиям.
13. ✅ **Достижения/летопись.** Локальная «Летопись подвигов» (первая победа
    над драконом, битва без потерь, неделя без пропуска хода). Полностью
    офлайн, тон «сказки» держит.
14. ✅ **Локализация.** Текстов уже много и они в коде. Перед переводами —
    вынести строки в CSV/`TranslationServer` (это ещё и подготовка к п.12).
    EN как первый язык; триаж конвейера CONCEPT это явно приветствует.

## Технический долг (не фичи, но вытекают из ревью)

- **Спрайты дракона/лича/друида** — заменить плейсхолдеры (п.7).
- **Spell icons**: 4 иконки на 10 заклинаний — нарисовать недостающие 6.
- **Тесты**: частично «таутологичные» (проверяют наличие нод). Постепенно
  заменять на поведенческие (как №38 — формулы и roundtrip'ы).
- **Аудио-луп OGG**: сейчас `finished → play()` с микро-паузой; проверить
  бесшовность и при желании выставлять `loop` на импорте.

## Добавлено в 0.2.1 (сверх плана)

- Найм новых существ на карте: пегасы (Роща Фей), лисы-оборотни (Лесник),
  Каменный Страж (Обелиск) — с еженедельными складами.
- Инструменты локализации в tools/ (extract_strings / localize_pass /
  build_csv) — новые строки проверяются на покрытие одной командой.

## Анти-идеи (не делать)

- Мультиплеер, крафт, замки, ферма ресурсов — вне скоупа CONCEPT.
- Усложнение экономики (жалованье, расходы войск) — ломает столп
  «уют, а не фарм».
- Смена 2D-стиля на «современный» минимализм — ломает столп лампового UI.
