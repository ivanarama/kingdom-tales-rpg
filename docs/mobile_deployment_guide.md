# Руководство по запуску и установке на телефон (Android)

## 1. Автоматическая сборка APK (в один клик)
В корневой папке проекта подготовлен скрипт:
- `build_android_apk.bat`

Просто запустите его двойным кликом:
1. Он автоматически соберет проект через Godot 4.7.2 в файл `builds/fairytale_rpg.apk`.
2. Если к компьютеру подключен Android-телефон по USB (с включенной отладкой по USB в настройках разработчика), скрипт спросит: `Установить прямо сейчас на подключенный телефон? (y/n)`.
3. При ответе `y` скрипт сам выполнит `adb install -r` и сразу запустит игру на телефоне!

---

## 2. Ручная установка APK на телефон
Если телефон не подключен по кабелю:
1. Возьмите готовый файл `builds/fairytale_rpg.apk`.
2. Отправьте его себе в **Telegram** («Избранное»), залейте на **Google Диск** / **Яндекс Диск** или перекиньте по USB-проводу.
3. Откройте файл на телефоне и нажмите **Установить** (если система запросит разрешение на установку из неизвестных источников — разрешите для проводника/Telegram).
4. Запустите игру «Сказки Королевства» из меню приложений телефона!

---

## 3. Управление на сенсорном экране (Mobile Touch)
- **Исследование карты:**
  - Одиночное касание (тап) по любой видимой клетке карты — прокладывает маршрут и отправляет героя в путь.
  - Свайп/перетаскивание пальцем — свободная прокрутка большой карты приключений.
  - Кнопки HUD («Конец Дня», «Книга Магии», «Профиль Рыцаря») увеличены под удобный нажим пальцем.
- **Тактический бой на гексах:**
  - Тап по зеленому гексу — перемещение бойца.
  - Тап по красному мечу на вражеском отряде — выбор направления атаки и удар.
  - **Долгое нажатие (0.35+ сек) на любого юнита** (или короткий тап по дружественному/нейтральному юниту) — открывает подробную карточку-инспектор:
    - Текущее и максимальное здоровье отряда.
    - Разброс урона.
    - Защита и скорость.
    - Ограничения сломанной стрелы для лучников.
- **Книга заклинаний и Артефакты:**
  - В бою и на карте все иконки заклинаний и слотов экипировки нажимаются пальцем. В профиле рыцаря можно экипировать и снимать артефакты в один тап.
